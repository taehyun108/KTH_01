# 집 PC에서 자막 받기 (Windows)

## 왜 필요한가요

GitHub 서버의 IP는 유튜브가 막아 두어서 **자막을 한 건도 못 가져옵니다**. 자막이 없으면
영상 내용을 알 수 없으니 리포트를 만들지 못합니다. 요즘 하루 1건씩만 올라오던 이유입니다.

가정용 인터넷은 막히지 않습니다. 그래서 **자막 받는 일만** 집 PC가 맡고, 요약과 발행은
그대로 GitHub가 합니다.

```
집 PC  ──자막만──▶  저장소(cache/)  ──읽음──▶  GitHub  ──▶  요약·발행
```

- **Gemini API 키는 PC에 넣지 않습니다.** 키는 지금처럼 GitHub 시크릿에만 둡니다.
- **PC가 꺼져 있어도 사이트는 그대로 돌아갑니다.** 자막이 없을 뿐이라, 최악이 지금 상태입니다.

---

## 1. 준비 (한 번만)

**Python** — <https://www.python.org/downloads/>
설치 첫 화면에서 아래 항목을 **반드시 체크**해 주세요.

> ☑ Add Python to PATH

**Git** — <https://git-scm.com/downloads> (기본값으로 설치하시면 됩니다)

둘 다 설치했으면 시작 메뉴에서 **명령 프롬프트**를 열고 아래를 한 줄씩 입력합니다.

```
cd %USERPROFILE%
git clone https://github.com/taehyun108/KTH_01.git
cd KTH_01
pip install -r requirements.txt
```

`C:\Users\<사용자이름>\KTH_01` 폴더가 만들어집니다.

---

## 2. 잘 되는지 먼저 확인

탐색기에서 `KTH_01\tools` 폴더를 열고 **`run-transcripts.bat`** 을 두 번 누르면 됩니다.
다만 처음에는 아래처럼 **확인만** 해 보시는 편이 좋습니다. 명령 프롬프트에서:

```
cd %USERPROFILE%\KTH_01
tools\run-transcripts.bat --limit 5 --no-push
```

`--limit 5` 는 5건만, `--no-push` 는 올리지 않고 받기만 한다는 뜻입니다.

**이렇게 나오면 성공입니다.**

```
[1/5] ✔ abc123   12,340자  삼프로TV 오늘의 시장...
```

`✔` 가 하나라도 보이면 **이 PC에서는 자막이 열린다**는 뜻이고, 이 방법이 통합니다.

**전부 `– 자막 없음` 이면** 이 PC에서도 막힌 것입니다. 그 화면을 알려 주시면 다른 방법을
찾아보겠습니다.

---

## 3. 진짜로 올리기

확인이 됐으면 옵션 없이 실행합니다.

```
tools\run-transcripts.bat
```

받아서 저장소에 올리는 것까지 한 번에 됩니다.

> **처음 올릴 때** 브라우저 창이 떠서 GitHub 로그인을 요구할 수 있습니다.
> 한 번 로그인해 두면 다음부터는 묻지 않습니다.

올린 뒤 다음 자동 실행(09:00 / 21:00)부터 이 자막이 쓰입니다.

---

## 4. 자동 실행 등록 (선택)

매번 직접 누르기 번거로우시면 **`install-schedule.bat`** 을 두 번 눌러 주세요.
매일 **08:20 과 20:20** 에 자동으로 돕니다. GitHub 아카이브가 09:00 / 21:00 에 도니까
그보다 40분 앞서 자막을 올려 두는 것입니다.

- PC가 꺼져 있던 시간대는 그냥 건너뜁니다.
- 해제하려면 **`uninstall-schedule.bat`** 을 누르시면 됩니다.
- 등록된 것은 **작업 스케줄러**에서 `KTH01-Transcripts-AM` / `-PM` 이름으로 보입니다.

---

## 자주 나오는 문제

**`'python'은(는) 내부 또는 외부 명령... 이 아닙니다`**
Python 설치할 때 *Add Python to PATH* 를 빠뜨린 것입니다. Python을 다시 설치하면서
그 항목을 체크하시면 됩니다.

**`git pull FAILED`**
인터넷이 끊겼거나 GitHub 로그인이 풀린 경우입니다. 명령 프롬프트에서
`cd %USERPROFILE%\KTH_01` 후 `git pull` 을 직접 실행해 보시면 원인이 나옵니다.

**글자가 깨져 보입니다**
`chcp 65001` 로 UTF-8을 켜 두었지만 일부 환경에서는 여전히 깨질 수 있습니다.
동작에는 문제가 없습니다. Windows Terminal 을 쓰시면 깔끔하게 보입니다.

**자막 캐시가 저장소를 너무 키우지 않나요**
45일 지난 것은 자동으로 지웁니다. 후보로 삼는 기간이 30일이라 그보다 오래된 자막은
쓸 일이 없습니다. 또 `cache/` 는 `site/` 밖이라 **웹사이트로 배포되지 않습니다**
(남의 영상 자막 전문이 공개되지 않도록 일부러 그렇게 두었습니다).
