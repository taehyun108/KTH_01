# 📘 PFM-Agent 설치·실행 가이드 (비개발자용)

이 문서는 **개발을 모르는 회사 PC 사용자**가 PFM-Agent를 설치하고 실행할 수 있도록
단계별로 안내합니다. 순서대로만 따라 하시면 됩니다.

> 💡 준비물: USB에 담긴 `PFM-Agent` 폴더 하나면 충분합니다.
> 인터넷이 차단된 사내 PC에서도 동작하도록 설계되어 있습니다.

---

## 1단계. 폴더 복사

1. USB의 **`PFM-Agent`** 폴더 전체를 회사 PC의 원하는 위치에 복사합니다.
   - 예: `D:\PFM-Agent` 또는 `C:\Users\내이름\PFM-Agent`
   - ⚠️ **한글·공백이 없는 경로**를 권장합니다. (예: `C:\PFMAgent`)
2. 폴더를 열면 아래 파일들이 보여야 합니다.
   - `first_time_setup.bat`  ← 처음 설치할 때 실행
   - `run_all.bat`           ← 평소 실행할 때 실행
   - `README.md`, `SETUP_GUIDE_KR.md` 등

---

## 2단계. 최초 설치 (딱 한 번만)

1. **`first_time_setup.bat`** 파일을 **더블클릭**합니다.
2. 검은 창(명령 프롬프트)이 뜨고 자동으로 아래 작업이 진행됩니다.
   - ✅ Python 패키지 관리자(uv) 준비
   - ✅ 백엔드 가상환경(`.venv`) 생성 및 라이브러리 설치
   - ✅ AI 모델 파일 준비 (BGE-M3 문서검색 / PaddleOCR 글자인식)
   - ✅ 설정 파일(`.env`) 자동 생성
3. **"설치가 완료되었습니다"** 메시지가 나오면 창을 닫아도 됩니다.
   - ⏳ 최초 1회는 수 분~십수 분 걸릴 수 있습니다. (라이브러리/모델 용량이 큼)

> ❓ **인터넷이 막혀 설치가 안 될 때**
> 개발자가 미리 `.venv`와 `models/` 폴더까지 채워둔 USB를 받았다면,
> `first_time_setup.bat`를 실행하지 않고 **3단계로 바로** 넘어가도 됩니다.

---

## 3단계. 설정값 입력 (P-GPT 연결)

1. 폴더 안의 **`.env`** 파일을 **메모장**으로 엽니다.
   (`.env.example`이 아니라 `.env` 입니다. 2단계에서 자동 생성됩니다.)
2. 아래 항목을 **회사에서 받은 값**으로 채웁니다.

```
LLM_PROVIDER=pgpt
PGPT_BASE_URL=https://사내-pgpt-주소/v1
PGPT_API_KEY=발급받은_키
PGPT_MODEL=사내_모델명
```

3. 저장하고 메모장을 닫습니다.

> 🔐 `.env` 파일에는 비밀 키가 들어갑니다. **외부로 공유하지 마세요.**

---

## 4단계. 실행

1. **`run_all.bat`** 파일을 **더블클릭**합니다.
2. 자동으로 아래 6가지를 점검한 뒤 실행합니다.
   - ✅ 설정 파일(`.env`) 과 P-GPT 정보
   - ✅ 필수 라이브러리 설치 여부
   - ✅ 저장 폴더(data/logs/output) 쓰기 가능 여부
   - ✅ 포트 사용 가능 여부
   - ✅ 내부 도구 서버(MCP) 를 실제로 켜서 확인
   - ✅ AI 모델 준비 상태 (없어도 실행은 가능)

   > 문제가 있으면 **무엇이 잘못됐고 어떻게 고치는지** 한글로 알려주고 멈춥니다.
   > 그대로 따라 하시면 됩니다.
3. 잠시 후 **PFM-Agent 창**이 뜨면 준비 완료입니다.
4. 채팅창에 하고 싶은 일을 **자연어**로 입력하세요.
   - 예: *"소듐이온배터리 최근 정책동향을 조사해서 보고서로 만들어줘"*

---

## 4-1단계. 처음이라면 — 예시 자료로 먼저 확인해 보기 (선택)

사내 자료를 아직 넣지 않았다면, 예시 자료로 동작을 먼저 확인할 수 있습니다.

1. `run_backend.bat` 을 실행해 둔 상태에서
2. 새 명령 프롬프트를 열고 아래를 실행합니다.

```
cd backend
uv run python ..\scripts\create_samples.py
```

3. PFM-Agent 화면에서 **"예시 요청 넣기"** 버튼을 누르고 **실행**합니다.
4. 잠시 후 `output` 폴더에 Word 보고서가 생기면 정상입니다.

> ⚠️ 예시 자료는 **동작 확인용**이며 실제 정책 자료가 아닙니다.

---

## 4-2단계. 화면을 자동으로 조작시키기

PFM-Agent 는 **말로 지시하면 화면을 직접 조작**할 수 있습니다.
예: *"브라우저를 열어 정책브리핑에서 소듐이온배터리를 검색해줘"*

동작 방식은 사람이 PC 를 쓰는 것과 같습니다.

1. 화면을 봅니다 (무엇이 있는지 읽습니다)
2. 다음에 무엇을 할지 판단합니다
3. **한 번만** 조작합니다 (클릭 / 입력 / 키 / 브라우저 열기)
4. 다시 화면을 보고 1번으로 돌아갑니다 → 목표를 달성하면 멈춥니다

> ⚠️ **조작할 때마다 승인 창이 뜹니다.** 내용을 확인하고 승인하세요.
> 승인하지 않으면 조작은 실행되지 않습니다.
> 멈추고 싶으면 언제든 **ESC** 를 누르거나 **빨간 정지 버튼**을 누르세요.

**끝없이 조작하지 않도록 4중 안전장치가 있습니다.**

| 상황 | 앱의 동작 |
|---|---|
| 조작이 너무 많아질 때 | 15회에서 자동 중단 (`.env` 의 `GUI_MAX_STEPS`) |
| 같은 곳만 계속 누를 때 | 3번 반복되면 "화면이 바뀌지 않았다"며 중단 |
| 화면에 없는 것을 누르려 할 때 | 실행하지 않고 건너뜀 (오클릭 방지) |
| 화면을 읽을 수 없을 때 | 조작을 **아예 시도하지 않음** |

자동 조작을 쓰지 않으려면 `.env` 에 `GUI_LOOP_ENABLED=false` 를 넣으세요.

## 4-3단계. 팀원과 대화·회의하기 (선택)

같은 그룹 구성원끼리 **카카오톡처럼** 대화하고 자료를 주고받을 수 있습니다.
화면 위쪽의 **"팀 협업"** 탭을 누르세요.

### 혼자 쓸 때
그냥 쓰시면 됩니다. 대화 내용이 내 PC 에 기록으로 남습니다.

### 여러 PC 가 함께 쓸 때 (사내망)

**한 대를 "호스트"로 정합니다.** (항상 켜 두는 PC 가 좋습니다)

1. **호스트 PC** — `.env` 를 메모장으로 열어 아래 두 줄을 바꿉니다.
   ```
   TEAM_SERVER_ENABLED=true
   BACKEND_HOST=0.0.0.0
   ```
   그리고 호스트 PC 의 IP 주소를 확인합니다.
   (명령 프롬프트에서 `ipconfig` 입력 → "IPv4 주소" 확인, 예: 10.20.30.40)

   > 💡 Windows 방화벽이 물어보면 **허용**을 눌러야 다른 PC 가 접속할 수 있습니다.
   > 회사 보안 정책상 막혀 있다면 전산 담당자에게 8756 포트 허용을 요청하세요.

2. **참여자 PC** — `.env` 에 호스트 주소를 적습니다.
   ```
   TEAM_SERVER_URL=http://10.20.30.40:8756
   ```

3. 각자 이름을 정합니다. (비워 두면 PC 이름이 표시됩니다)
   ```
   TEAM_DISPLAY_NAME=김태현
   ```

4. 모두 `run_all.bat` 을 실행하면 같은 대화방에서 이야기할 수 있습니다.

### 사용 방법

| 하고 싶은 것 | 방법 |
|---|---|
| 💬 대화방 만들기 | 왼쪽 위 **+ 대화** |
| 📋 회의 시작하기 | 왼쪽 위 **+ 회의** |
| 📎 파일·사진·영상 보내기 | 입력창 왼쪽 **클립 버튼** |
| ✉️ 메시지 보내기 | 입력 후 **Enter** (줄바꿈은 Shift+Enter) |
| 📄 회의록 보기 | 오른쪽 위 **기록 보기** |
| 🔚 회의 끝내기 | 오른쪽 위 **회의 종료** |

> ⚠️ **기록은 지워지지 않습니다.**
> 메시지를 삭제해도 화면에서만 가려지고, "누가 언제 지웠는지"는 기록에 남습니다.
> 회의 기록은 `logs/team.jsonl` 과 `data/team.db` 에 보관됩니다.
> 업무용 기록이므로 **개인적인 내용은 주고받지 마세요.**

> 💡 Agent 가 만든 보고서를 대화방에 바로 올릴 수도 있습니다.
> 예: *"소듐이온배터리 보고서를 만들어서 주간회의 방에 공유해줘"*

| 상황 | 방법 |
|---|---|

| 🌐 **접속 가능 사이트** | 회사가 허용한 도메인만 열립니다 (`backend/app/config/whitelist.json`) |

## ❓ 자주 묻는 문제 (문제 해결)

**Q. 더블클릭했더니 창이 잠깐 떴다 사라져요.**
→ 폴더 경로에 한글/공백이 있을 수 있습니다. `C:\PFMAgent` 처럼 영문 경로로 옮겨 다시 시도하세요.

**Q. "python을 찾을 수 없습니다" 라고 나와요.**
→ `first_time_setup.bat`을 먼저 실행했는지 확인하세요. 가상환경(`.venv`)이 있어야 합니다.

**Q. "P-GPT 연결 실패" 메시지가 나와요.**
→ 3단계의 `.env` 값(`PGPT_BASE_URL`, `PGPT_API_KEY`, `PGPT_MODEL`)이 올바른지 확인하세요.
   사내망에 연결되어 있는지도 확인이 필요합니다.

**Q. 인터넷이 막혀서 웹 검색이 안 돼요.**
→ 정상입니다. 웹 검색은 **선택 기능**이며, 실패 시 자동으로 **사내 RAG 검색**만으로 동작합니다.

**Q. 다른 PC로 옮기고 싶어요.**
→ `PFM-Agent` 폴더를 통째로 복사하면 됩니다. (모든 파일이 폴더 안에 있는 포터블 구조)
   `run_all.bat` / `run_backend.bat` 로 실행하는 한 폴더 위치가 달라도 그대로 동작합니다.

**Q. 폴더 이름을 바꾸거나 위치를 옮겼더니 일부 명령이 안 돼요.**
→ `backend\.venv` 안의 실행 파일에는 **처음 설치했을 때의 경로가 새겨져 있습니다.**
   그래서 폴더를 옮기면 `uv run uvicorn` 처럼 직접 실행하는 명령이 실패할 수 있습니다.
   - **앱 실행(`run_all.bat`)은 영향 없습니다.** 이 문제를 피하는 방식으로 만들어져 있습니다.
   - 그래도 문제가 계속되면 `backend\.venv` 폴더를 **삭제**하고
     `first_time_setup.bat` 를 다시 실행하세요. (인터넷 필요)
   - `run_all.bat` 의 점검 단계가 이 상태를 감지해 한글로 알려줍니다.

**Q. "근거가 부족해 다시 찾습니다" 라는 메시지가 나와요.**
→ 정상입니다. 찾은 자료가 부족하다고 판단되면 **검색어를 바꿔 한 번 더 찾아봅니다.**
   최대 회차는 정해져 있어 계속 반복되지는 않으며, 다시 찾아도 부족하면
   보고서를 만든 뒤 "사람이 검토하세요" 라고 안내합니다.
   재검색이 필요 없다면 `.env` 에 `AGENT_MAX_ITERATIONS=1` 로 두면 꺼집니다.

**Q. "문서 검색 모델이 없습니다" 라고 나와요.**
→ 정상입니다. 모델이 없으면 **키워드 검색**으로 자동 전환되어 계속 동작합니다.
   검색 정확도를 높이려면 담당자가 인터넷 되는 PC 에서 모델을 받아 `models` 폴더째 전달해야 합니다.

**Q. "화면 인식을 사용할 수 없습니다" 라고 나와요.**
→ 글자 인식(OCR) 기능이 설치되지 않았거나 원격 접속 환경일 때 나옵니다.
   화면 조작이 필요 없는 작업(자료 검색·보고서 작성)은 정상 동작합니다.

**Q. 화면 관련 기능이 되는지 한 번에 확인하고 싶어요.**
→ 아래를 실행하면 캡처·글자 인식·마우스 조작이 되는지 항목별로 알려줍니다.

```
cd backend
uv run python ..\scripts\verify_display.py
```

   마우스를 실제로 움직여 확인까지 하려면 뒤에 `--allow-input` 을 붙이세요.
   (확인 후 마우스를 원래 위치로 되돌립니다)

**Q. 글자 인식(OCR) 모델은 어디에 있어야 하나요?**
→ `models\ocr` 폴더 아래 `det` / `rec` / `cls` 세 폴더입니다.
   **반드시 PFM-Agent 폴더 안에 있어야** USB 로 옮길 때 함께 따라갑니다.
   인터넷 되는 PC 에서 아래를 실행한 뒤 `models` 폴더째 복사하세요.

```
cd backend
uv run python ..\scripts\download_models.py
```

**Q. 팀 협업에서 다른 PC 가 접속이 안 돼요.**
→ 아래를 차례로 확인하세요.
   1. 호스트 PC 의 `.env` 에 `TEAM_SERVER_ENABLED=true`, `BACKEND_HOST=0.0.0.0` 이 있는지
   2. 참여자 PC 의 `TEAM_SERVER_URL` 주소가 호스트 IP 와 맞는지 (`ipconfig` 로 확인)
   3. 호스트 PC 에서 **Windows 방화벽**이 8756 포트를 막고 있지 않은지
   4. 두 PC 가 **같은 사내망**에 있는지 (VPN/게스트망은 분리돼 있을 수 있음)
   호스트 PC 의 브라우저에서 `http://127.0.0.1:8756/docs` 가 열리면 백엔드는 정상입니다.

**Q. 파일이 너무 크다고 나와요.**
→ 기본 상한은 100MB 입니다. `.env` 의 `TEAM_MAX_ATTACHMENT_MB` 값을 올리면 됩니다.
   다만 파일은 호스트 PC 의 `data/attachments` 에 쌓이므로 용량을 확인하세요.

**Q. 대화 기록은 어디에 있나요?**
→ 호스트 PC 의 아래 위치에 있습니다. USB 로 폴더째 옮기면 기록도 함께 갑니다.
   - `data/team.db` — 대화·회의·첨부 목록
   - `data/attachments/` — 주고받은 파일 원본
   - `logs/team.jsonl` — 활동 기록 (메모장으로 열어볼 수 있습니다)

**Q. ESC 를 눌러도 멈추지 않아요.**
→ 다른 프로그램이 ESC 키를 먼저 가져갔을 수 있습니다.
   **PFM-Agent 화면을 클릭해 활성화한 뒤 ESC** 를 누르거나, 화면의 **빨간 정지 버튼**을 사용하세요.
