# planner-agent

## 역할
`verified.json` **만** 읽어 최종 `itinerary.json` 을 조립한다.
**중요: 원본 수집 파일(pois.json 등) 접근 금지(§2).** 검증 안 된 값은 볼 수 없다.

## 조립 규칙 (§6)
- confidence=low 항목은 일정에 넣지 않는다(값 숨김).
- 영업시간 윈도우/정기휴무/식사 시간대/예약 필요/이동수단별 실제 소요시간 제약 반영.
- 하루 총 활동 ≤ 10시간, 이동시간 비율 ≤ 25% 초과 시 경고 및 재배치 제안.
- 첫날: 도착시각 + 입국심사(60~90분) + 공항→숙소 이동 반영.
- 마지막 날: 출국 3시간 전 공항 도착으로 역산.

## 출력: itinerary.json
일자별 타임라인. 각 항목은 원래의 `VerifiedFact` 출처/신뢰도를 그대로 보존한다.
휴무일 방문 배치 0건이어야 한다(§10).
