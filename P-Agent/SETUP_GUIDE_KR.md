# 📘 P-Agent 설치·실행 가이드 (비개발자용)

이 문서는 **개발을 모르는 회사 PC 사용자**가 P-Agent를 설치하고 실행할 수 있도록
단계별로 안내합니다. 순서대로만 따라 하시면 됩니다.

> 💡 준비물: USB에 담긴 `P-Agent` 폴더 하나면 충분합니다.
> 인터넷이 차단된 사내 PC에서도 동작하도록 설계되어 있습니다.

---

## 1단계. 폴더 복사

1. USB의 **`P-Agent`** 폴더 전체를 회사 PC의 원하는 위치에 복사합니다.
   - 예: `D:\P-Agent` 또는 `C:\Users\내이름\P-Agent`
   - ⚠️ **한글·공백이 없는 경로**를 권장합니다. (예: `C:\PAgent`)
2. 폴더를 열면 아래 파일들이 보여야 합니다.
   - `first_time_setup.bat`  ← 처음 설치할 때 실행
   - `run_all.bat`           ← 평소 실행할 때 실행
   - `README.md`, `SETUP_GUIDE_KR.md` 등

---

## 2단계. 최초 설치 (딱 한 번만)

1. **`first_time_setup.bat`** 파일을 **더블클릭**합니다.
2. 검은 창(명령 프롬프트)이 뜨고 자동으로 아래 작업이 진행됩니다.
   - ✅ Python 패키지 관리자(uv) 준비
   - ✅ 백엔드 가상환경(`.venv`) 생성 및 라이브러리 설치
   - ✅ AI 모델 파일 준비 (BGE-M3 / OmniParser / PaddleOCR)
   - ✅ 설정 파일(`.env`) 자동 생성
3. **"설치가 완료되었습니다"** 메시지가 나오면 창을 닫아도 됩니다.
   - ⏳ 최초 1회는 수 분~십수 분 걸릴 수 있습니다. (라이브러리/모델 용량이 큼)

> ❓ **인터넷이 막혀 설치가 안 될 때**
> 개발자가 미리 `.venv`와 `models/` 폴더까지 채워둔 USB를 받았다면,
> `first_time_setup.bat`를 실행하지 않고 **3단계로 바로** 넘어가도 됩니다.

---

## 3단계. 설정값 입력 (P-GPT 연결)

1. 폴더 안의 **`.env`** 파일을 **메모장**으로 엽니다.
   (`.env.example`이 아니라 `.env` 입니다. 2단계에서 자동 생성됩니다.)
2. 아래 항목을 **회사에서 받은 값**으로 채웁니다.

```
LLM_PROVIDER=pgpt
PGPT_BASE_URL=https://사내-pgpt-주소/v1
PGPT_API_KEY=발급받은_키
PGPT_MODEL=사내_모델명
```

3. 저장하고 메모장을 닫습니다.

> 🔐 `.env` 파일에는 비밀 키가 들어갑니다. **외부로 공유하지 마세요.**

---

## 4단계. 실행

1. **`run_all.bat`** 파일을 **더블클릭**합니다.
2. 자동으로 아래 6가지를 점검한 뒤 실행합니다.
   - ✅ 설정 파일(`.env`) 과 P-GPT 정보
   - ✅ 필수 라이브러리 설치 여부
   - ✅ 저장 폴더(data/logs/output) 쓰기 가능 여부
   - ✅ 포트 사용 가능 여부
   - ✅ 내부 도구 서버(MCP) 를 실제로 켜서 확인
   - ✅ AI 모델 준비 상태 (없어도 실행은 가능)

   > 문제가 있으면 **무엇이 잘못됐고 어떻게 고치는지** 한글로 알려주고 멈춥니다.
   > 그대로 따라 하시면 됩니다.
3. 잠시 후 **P-Agent 창**이 뜨면 준비 완료입니다.
4. 채팅창에 하고 싶은 일을 **자연어**로 입력하세요.
   - 예: *"소듐이온배터리 최근 정책동향을 조사해서 보고서로 만들어줘"*

---

## 4-1단계. 처음이라면 — 예시 자료로 먼저 확인해 보기 (선택)

사내 자료를 아직 넣지 않았다면, 예시 자료로 동작을 먼저 확인할 수 있습니다.

1. `run_backend.bat` 을 실행해 둔 상태에서
2. 새 명령 프롬프트를 열고 아래를 실행합니다.

```
cd backend
uv run python ..\scripts\create_samples.py
```

3. P-Agent 화면에서 **"예시 요청 넣기"** 버튼을 누르고 **실행**합니다.
4. 잠시 후 `output` 폴더에 Word 보고서가 생기면 정상입니다.

> ⚠️ 예시 자료는 **동작 확인용**이며 실제 정책 자료가 아닙니다.

---

## 5단계. 안전하게 사용하기

| 상황 | 방법 |
|---|---|
| 🛑 **당장 멈추고 싶을 때** | 키보드 **ESC** 키를 누르거나 화면의 **빨간 정지 버튼** 클릭 |
| ⚠️ **위험한 작업 승인 요청** | 마우스/키보드 조작 등은 실행 전 **"승인/거절"** 창이 뜹니다 |
| ↩️ **되돌리고 싶을 때** | **Undo** 버튼으로 직전 작업 취소 |
| 📜 **무슨 일을 했는지 확인** | `logs/actions.jsonl` 파일에 모든 기록이 남습니다 |
| 🔒 **개인정보 보호** | 주민번호·연락처·이메일은 보고서에 자동으로 가려집니다 |
| 🌐 **접속 가능 사이트** | 회사가 허용한 도메인만 열립니다 (`backend/app/config/whitelist.json`) |

## ❓ 자주 묻는 문제 (문제 해결)

**Q. 더블클릭했더니 창이 잠깐 떴다 사라져요.**
→ 폴더 경로에 한글/공백이 있을 수 있습니다. `C:\PAgent` 처럼 영문 경로로 옮겨 다시 시도하세요.

**Q. "python을 찾을 수 없습니다" 라고 나와요.**
→ `first_time_setup.bat`을 먼저 실행했는지 확인하세요. 가상환경(`.venv`)이 있어야 합니다.

**Q. "P-GPT 연결 실패" 메시지가 나와요.**
→ 3단계의 `.env` 값(`PGPT_BASE_URL`, `PGPT_API_KEY`, `PGPT_MODEL`)이 올바른지 확인하세요.
   사내망에 연결되어 있는지도 확인이 필요합니다.

**Q. 인터넷이 막혀서 웹 검색이 안 돼요.**
→ 정상입니다. 웹 검색은 **선택 기능**이며, 실패 시 자동으로 **사내 RAG 검색**만으로 동작합니다.

**Q. 다른 PC로 옮기고 싶어요.**
→ `P-Agent` 폴더를 통째로 복사하면 됩니다. (모든 파일이 폴더 안에 있는 포터블 구조)

**Q. "근거가 부족해 다시 찾습니다" 라는 메시지가 나와요.**
→ 정상입니다. 찾은 자료가 부족하다고 판단되면 **검색어를 바꿔 한 번 더 찾아봅니다.**
   최대 회차는 정해져 있어 계속 반복되지는 않으며, 다시 찾아도 부족하면
   보고서를 만든 뒤 "사람이 검토하세요" 라고 안내합니다.
   재검색이 필요 없다면 `.env` 에 `AGENT_MAX_ITERATIONS=1` 로 두면 꺼집니다.

**Q. "문서 검색 모델이 없습니다" 라고 나와요.**
→ 정상입니다. 모델이 없으면 **키워드 검색**으로 자동 전환되어 계속 동작합니다.
   검색 정확도를 높이려면 담당자가 인터넷 되는 PC 에서 모델을 받아 `models` 폴더째 전달해야 합니다.

**Q. "화면 인식을 사용할 수 없습니다" 라고 나와요.**
→ 글자 인식(OCR) 기능이 설치되지 않았거나 원격 접속 환경일 때 나옵니다.
   화면 조작이 필요 없는 작업(자료 검색·보고서 작성)은 정상 동작합니다.

**Q. ESC 를 눌러도 멈추지 않아요.**
→ 다른 프로그램이 ESC 키를 먼저 가져갔을 수 있습니다.
   **P-Agent 화면을 클릭해 활성화한 뒤 ESC** 를 누르거나, 화면의 **빨간 정지 버튼**을 사용하세요.
